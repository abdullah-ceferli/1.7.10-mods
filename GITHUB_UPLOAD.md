# GitHub repository

Use this workspace folder as the repository root. All mod projects stay in their existing folders, and the root can be renamed later. Keep the existing `.git` directory and add this root folder in GitHub Desktop.

Each project has its own README, license notices and build prerequisites. Local toolchains, caches, test worlds and generated builds are covered by ignore rules. Files already tracked by Git stay tracked until explicitly reviewed; ignore rules do not remove them from history or the index.

The latest existing built mod JARs are in [Latest-Mods](Latest-Mods/README.md), with dependencies, alternatives and a version/hash list. This curated folder, including its JAR files, is included in Git; generated project build directories stay ignored. In GitHub Desktop, commit these changes and then use Push origin to show the folder on GitHub. SRP still has no playable production JAR. Croptopia and Cultural Delights are initial tested backports with remaining compatibility work.

Original licenses and credits remain in each project. This workspace does not grant new redistribution rights to restricted upstream material. No commit, remote, push or publication was performed by this preparation.
